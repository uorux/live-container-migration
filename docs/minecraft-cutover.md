# Minecraft cutover: recusant → k3s

The runbook for moving the 12 packs off recusant (Velocity, AutoServer, HAProxy) onto on-demand
LivePods. Manifests: `deploy/homelab/minecraft` (generated by `tools/gen-minecraft.py`) and
`deploy/homelab/minecraft-gw` (the router-path VIP gateway); VPS ingresses: `deploy/standalone`.
Window: announce 3 h; expect about 2 h, mostly the final copy and its checksum pass.

## The copy

A temporary loader pod mounts every world (not in Git; apply and delete by hand):

```sh
packs="atm9 atm10 bettermc evolution ob2 sb4 skies2 p2haustian dungeonheroes integratedmc abyssalascent sdfs"
{ cat <<'EOF'
apiVersion: v1
kind: Pod
metadata: {name: mc-loader, namespace: minecraft}
spec:
  containers:
  - name: rsync
    image: alpine:3.22
    command: ["sh", "-c", "apk add --no-cache rsync >/dev/null && sleep infinity"]
    volumeMounts:
EOF
for p in $packs; do echo "    - {name: $p, mountPath: /data/$p}"; done
echo "  volumes:"
for p in $packs; do echo "  - {name: $p, persistentVolumeClaim: {claimName: $p-data}}"; done
} | kubectl apply -f -
```

Per pack, from recusant (with a kubeconfig) or anywhere that can read `/mc` and run kubectl.
`<src>` is a snapshot during pre-seeding, the `mc.pre-k3s` snapshot at T0. CurseForge packs live
in versioned directories (atm9 → `/mc/atm9-0.3.5`): map each by hand.

```sh
rsync -aHX --numeric-ids --chown=1000:1000 --delete --info=progress2 \
  --exclude-from=mc-exclude.txt \
  --rsh='kubectl exec -i -n minecraft mc-loader --' \
  <src>/<dir>/ x:/data/<pack>/
```

`mc-exclude.txt` (agreed with the image agent; the image owns mods and loader files, and Nix
symlinks into /nix/store would arrive dangling):

```
/mods/
/libraries/
/versions/
/cache/
/.fabric/
/download/
/serverinstall_*
/ftb-server-installer*
/*-installer.jar*
/*.bat
/*.sh
/logs/
/crash-reports/
/.mixin.out/
/dynamic-data-pack-cache/
/modernfix/
/user_jvm_args.txt
/eula.txt
/.mc-managed
/whitelist.json
/ops.json
/session.lock
/world/session.lock
```

Run `find /mc -xdev -type l -lname '/nix/store/*'` first: anything it lists that isn't excluded
above needs a decision. sdfs also needs `world_nether/`, `world_the_end/` and its plugin data
(copied by default; Via and the exporter come from the image).

## T0

1. Announce. Stop Velocity, then `systemctl stop 'minecraft-*'`; `systemctl mask --runtime` on
   Velocity, the lobby and every backend unit. Wait for `pgrep java` to be empty; each log ends
   with the world saved.
2. Snapshot `/mc` read-only as `mc.pre-k3s`: the rollback point.
3. Final sync from `mc.pre-k3s`, every pack (deltas only after the pre-seed).
4. Verify: the same rsync with `-anc` (checksums, dry run) lists nothing per pack.
5. `kubectl -n minecraft delete pod mc-loader`.
6. Router: port-forward 25565 → `10.0.0.250`. VPS boxes: HAProxy's Minecraft backend →
   `127.0.0.1:25566 send-proxy-v2`, `systemctl reload haproxy`.
7. Test from outside the LAN (phone hotspot):
   - the bare domain shows the menu; pick a pack: held, woken, transferred, joined;
   - `<pack>.<domain>` for a Forge 1.20.1, a NeoForge 1.21.1 and a Fabric pack, and sdfs;
   - the same through a VPS box;
   - a non-whitelisted account is refused by the server;
   - with a player connected: `lcm migrate livepod/<pack> -n minecraft --to auto` (pause of a
     few seconds, no disconnect) and `curl -X POST <active gateway admin>/vip/handoff` (pause of
     ~0.1 s);
   - leave one pack empty 10 min: it goes `Asleep`, the world saved.
8. Open. Watch `lcm history`, the lcm dashboard, and the alerts.

## Rollback

| When | How |
|---|---|
| Before anyone played in k3s | Router forward and box HAProxy back to recusant, `systemctl unmask` + start Velocity. LivePods stay asleep. |
| After play in k3s | Same, but first stop every pack: `kubectl annotate livepod --all -n minecraft lcm.rooty.dev/paused=true` (blocks new pods), then `kubectl -n minecraft delete pod -l app.kubernetes.io/part-of=minecraft` (SIGTERM saves; waits up to 180 s). and reverse-sync `/data/<pack>/` → `/mc/<dir>/` with the same excludes, `chown -R mc:mc`, `nixos-rebuild switch` on recusant to restore the Nix symlinks. Or restore `mc.pre-k3s` and drop the k3s-era play. |

Keep recusant's Minecraft config and `/mc` for 1-2 weeks; then disable its services in a
nixos-dots PR.

## Plan B: no router path yet

If the VIP gateway isn't trusted by Friday, leave the router pointing at recusant and run an
lcm-gateway there behind its HAProxy, exactly like a VPS box (`deploy/standalone`). Everything
else is the same; move the router to the VIP later without downtime, since every gateway serves
the same relays.
